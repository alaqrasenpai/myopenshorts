# StreamClip Studio AI 🎬⚡
### AI-Powered Short-Form Clipper, Multi-Track OpenCut Editor & Automated Publisher for Twitch, Kick & YouTube

**StreamClip Studio AI** هو نظام متكامل ومفتوح المصدر لتحويل الستريمات الطويلة والفيديوهات إلى مقاطع قصيرة (Clips / Shorts / TikToks / Reels) عمودية بنسبة 9:16 ذات معدل انتشار عالي (High Virality)، مستوحى من أحدث تقنيات:
* **OpenShorts**: لاكتشاف اللحظات الفيروسية والتفريغ الصوتي وتتبع الوجه.
* **Chopify**: لتحليل طاقة الصوت والقمم الحماسية محلياً.
* **Clipzi**: لتجربة المستخدم الأنيقة وتحديد توقيت التايم لاين.
* **OpenCut** (`opencut-app/opencut`): **لمحرر التايم لاين اليدوي متعدد المسارات في حال رغبت بإجراء تعديلات يدوية على الكليب**.
* **Video-Use** (`browser-use/video-use`): للمونتاج بالأوامر النصية الذكية (Agentic Editing) وحذف فترات الصمت مع تنعيم صوتي 30ms Micro-fades لمنع طقطقة القص.
* **AutoClip** (`zhouxiaoka/autoclip`): لتوليد أغلفة الفيديوهات (Viral Covers) وحزم النشر الجاهزة لـ TikTok و YouTube Shorts و Instagram Reels.

## 🌟 أبرز مميزات المنصة (Key Features)

### 1. استقبال الستريمات من جميع المنصات الرئيسية
- **Twitch**: يدعم الستريم المباشر (Live) ومقاطع الـ VODs والـ Clips.
- **Kick**: يدعم البثوث المباشرة وفيديوهات الـ VODs من Kick.
- **YouTube**: يدعم بثوث اليوتيوب المباشرة ومقاطع الفيديو الطويلة.
- **رفع ملف فيديو مباشر (Direct File Upload)**: إمكانية سحب وإفلات أي ملف فيديو محلي (MP4, MKV, MOV, WebM).

### 2. تمييز اللقطات الذكية والفيروسية (Smart AI Highlight Detection)
- **تحليل قمم الحماس والصراخ (Audio Energy & Excitement Spikes)**: قياس طاقة الصوت (RMS) لتمييز لحظات الصراخ، الضحك الشديد، والحماس أثناء اللعب.
- **التحليل الدلالي عبر الـ LLM**: فحص سياق الكلام، النكات، الـ Clutch، والردود الدرامية.
- **حساب درجة الفيروسية (Virality Score 1-100)**: إعطاء تقييم دقيق لكل لقطة مع سبب اختيارها واقتراح عنوان جذاب (Hook Title).
- **عرض توقيت اللقطة بدقة على التايم لاين**: يوضح لك بالضبط من أي ثانية/دقيقة إلى أي ثانية تم أخذ الكليب (مثال: `01:14:20 - 01:15:05`).

### 3. محرر التايم لاين اليدوي المتقدم (OpenCut Timeline Editor) ✂️
> **ميزة مخصصة عند رغبتك في تعديل الكليب يدوياً كبرامج المونتاج الاحترافية (CapCut / Premiere):**
- **مسارات متعددة (Multi-Track)**: مسار الفيديو مع أجزاء قابلة للسحب، مسار الصوت مع الـ Waveform، ومسار النصوص.
- **أداة القص الدقيق (Split / Razor)**: قص الكليب عند موضع المؤشر إلى أجزاء متعددة.
- **حذف وتعديل الأجزاء**: إمكانية حذف أي مقطع غير مرغوب فيه بضغطة زر.
- **تحكم فوري بالأبعاد والتدرج اللوني**: تحويل الأبعاد بين 9:16 و 16:9 و 1:1، مع خيارات تدرج لوني سينمائي أو حيوي.

### 4. المونتاج بالأوامر الذكية والصوت النقي (Video-Use Integration) 🤖
- **المونتاج بالأوامر الطبيعية (Agentic Editing)**: اكتب للأداة: *"احذف الصمت وضع تدرج سينمائي واجعل الإيقاع سريعاً"* وسيقوم الذكاء الاصطناعي بتنفيذ التعديل فوراً!
- **تنعيم صوتي مضاد للطقطقة (30ms Audio Micro-fades)**: تطبيق تلاشٍ صوتي ناعم بمقدار 30ms عند حواف كل قص لمنع أصوات الطقطقة المزعجة الناتجة عن القص الحاد.
- **كشف وحذف فترات الصمت (Silence Removal)**: فحص فترات الهدوء والتردد وحذفها للحفاظ على وتيرة سريعة وجذابة للجمهور.

### 5. حزمة النشر الذكي وتوليد الأغلفة (AutoClip Integration) 📢
- **توليد غلاف فيروسي (Viral Cover / Thumbnail)**: التقاط اللقطة الأكثر حماساً من الكليب وطباعة العنوان بخط عريض جذاب وجاهز للتحميل كصورة غلاف.
- **حزم نشر مجهزة بنقرة واحدة (One-Click Copy Packages)**:
  - **TikTok**: عنوان فيروسي + وصف + هاشتاجات تريند.
  - **YouTube Shorts**: عنوان متوافق مع SEO + وصف كامل + وسوم Tags.
  - **Instagram Reels**: كابشن تفاعلي + هاشتاجات مخصصة.

### 6. أنماط وإعدادات المونتاج الذكية (Layout Presets & Samples)
- 🎮 **Streamer Split (Gaming Style)**: وجه الستريمر بالأعلى بنسبة 38%، وشاشة اللعبة بالأسفل بنسبة 62%.
- 🎬 **Cinematic Blurred Background**: شاشة الستريم 16:9 بالمنتصف مع خلفية مموهة ومتحركة تملأ الشاشة الطولية.
- 👤 **Smart Face Tracking (9:16)**: تتبع ذكي لوجه المتحدث وإبقائه في المنتصف.
- ✨ **إمكانية رفع Samples لأنماط مونتاج مخصصة**: رفع لقطة شاشة لنمط المونتاج أو الـ Overlay المفضل لحفظه كنمط إيديت جديد.

### 7. الترجمات المتحركة الاحترافية (Animated Captions)
- 🔥 **Hormozi Style**: خط عريض (Impact)، تلوين الكلمة المنطوقة فوراً بالأصفر الفاقع مع إطار أسود.
- ⚡ **Neon Gamer**: إضاءة نيون فوشية وسماوية تناسب أجواء الألعاب.
- 🎤 **Karaoke Wave**: تلوين متتابع وانسيابي للكلمات أثناء نطقها.
- ⚪ **Sleek Minimal**: خط عصري بسيط وأنيق.

### 8. نظام مفاتيح الذكاء الاصطناعي الخاص بالمستخدم (BYO AI Key)
- يمكن لكل مستخدم إدخال مفتاح الـ API الخاص به لاستخدام حصته الشخصية:
  - **Google Gemini API** (موصى به: مجاني، سريع جداً، ويدعم سياق الستريم الطويل عبر Gemini 2.0 Flash).
  - **OpenAI API** (GPT-4o / GPT-4o-mini).
  - **Groq Cloud API** (LLaMA 3.3 + تفريغ Whisper فائق السرعة).
- اختبار وتحقق فوري من صلاحية المفتاح قبل استخدامه.
- خيار التفريغ الصوتي المحلي بالكامل عبر **Faster-Whisper** مجاناً بدون الحاجة لأي مفاتيح أو إنترنت.

## 🚀 طريقة التشغيل (Quick Start)

### المتطلبات الأساسية:
- **Python 3.11+** (تم اختباره على Python 3.12).
- **Node.js 18+** (اختياري فقط في حال أردت تعديل كود الـ Frontend، لأن الـ build مجهز بالفعل).
- **FFmpeg** (مثبت على الجهاز وموجود في الـ PATH).

### التشغيل المباشر:
1. انقر نقراً مزدوجاً على الملف:
   👉 [start.bat](file:///d:/Projects/ClipsProject/start.bat)
   *أو نفذ الأمر التالي في الطرفية (Terminal):*
   ```bash
   python run.py
   ```
2. افتح المتصفح على الرابط:
   👉 **http://localhost:8000**

## 🛠️ خطوات الاستخدام (Workflow):
1. **إعداد مفتاح الذكاء الاصطناعي**: اضغط على زر "إعداد مفتاح الـ AI" في الأعلى وضع مفتاح Gemini المجاني أو OpenAI أو Groq.
2. **إدخال رابط الستريم**: ضع رابط بث Twitch أو Kick أو YouTube، أو اسحب وأفلت ملف فيديو.
3. **التحليل الذكي**: سيقوم النظام تلقائياً باستخراج الصوت، تفريغ الكلمات بدقة، كشف كاميرا الستريمر، واستخراج أفضل المقاطع الفيروسية.
4. **خيارات المونتاج والتعديل**:
   - **مونتاج فوري (9:16)**: رندرة وتصدير فوري بنقرة واحدة.
   - **استوديو القوالب (Clip Studio)**: تعديل موضع كاميرا الستريمر، النمط، وتنسيق الترجمة (Hormozi, Neon, إلخ).
   - **محرر التايم لاين اليدوي (OpenCut)**: قص يدوي، حذف مقاطع، تنعيم صوتي 30ms، وتعديل عبر أوامر الذكاء الاصطناعي.
   - **حزمة النشر والغلاف (AutoClip)**: توليد صورة الغلاف ونسخ نصوص النشر الجاهزة لـ TikTok و Shorts و Reels.
